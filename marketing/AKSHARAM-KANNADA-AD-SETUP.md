# Aksharam Kannada — Meta ad: step-by-step (Ads Manager)

Videos: **Aksharam-Kannada-Ad-9x16.mp4** (Reels / Stories) and **Aksharam-Kannada-Ad-4x5.mp4** (Feed) — add BOTH to the ad;
Meta shows the right shape in each place.

Open **adsmanager.facebook.com** → account **Vishweshwara Sanskrit - Main Ads** → **+ Create**.

## 1. Campaign
- Objective: **Traffic** · Name: `Aksharam Kannada — Mac` · Advantage+ campaign budget: **OFF**

## 2. Two ad sets (two audiences, separate budgets)

### Ad set A — Karnataka
- Name: `Karnataka`
- Conversion location: **Website** · Goal: **Landing page views**
- Budget: **₹150 / day**, end date **10 days** later
- Locations: **Karnataka** (region). Optional extra weight: Bengaluru +40 km, Mysuru, Mangaluru, Hubballi, Dharwad,
  Belagavi, Udupi, Shivamogga, Tumakuru, Davanagere, Kalaburagi, Ballari.
- Age **18–55** · Detailed targeting (suggestions): **MacBook**, **MacBook Pro**, **Apple Inc.**
- Placements: Advantage+

### Ad set B — Kannadigas in the USA
- Name: `USA Kannadigas`
- Budget: **₹250 / day** (US views cost more), end date **10 days** later
- Locations (each **+40 km**): San Jose, Sunnyvale, Santa Clara, Fremont (Bay Area) · Seattle, Bellevue, Redmond ·
  Dallas, Irving, Plano · Houston · Austin · Chicago, Naperville · Edison & Jersey City (New Jersey) · Atlanta ·
  Novi (Detroit) · Boston · Ashburn (Virginia) · Raleigh · Charlotte · Phoenix · Irvine
- Age **22–55**
- **Languages:** type `Kannada` and add it. (This finds people who use Facebook in Kannada; if Meta says the audience
  is too small, remove the language and instead type `Kannada` / `Karnataka` / `Sandalwood` in Detailed targeting
  and add whatever Meta offers.)
- Detailed targeting (suggestions): **MacBook**, **MacBook Pro**
- Placements: Advantage+

## 3. The ad (same in both ad sets)
- Format: **Single video** → add **both** videos (9:16 and 4:5)
- Primary text:
  ```
  ಮ್ಯಾಕ್‌ನಲ್ಲಿ ಕನ್ನಡ ಟೈಪಿಂಗ್ ಈಗ ಸುಲಭ! 🙏
  Type kannaDa → ಕನ್ನಡ in WhatsApp, Gmail, Word — every app on your Mac.
  Same keys as Baraha & Nudi. Sanskrit (संस्कृतम्) included.
  Free 7-day trial · then ₹99 once, yours for life.
  ```
- Headline: `Kannada on your Mac — ಈಗ ಸುಲಭ`
- Description: `Free 7-day trial · ₹99 once`
- Call to action: **Download** (or Learn more) · Website: `https://vishweshwarasanskrit.com/aksharam`
- Turn OFF Advantage+ creative enhancements.

## 4. Publish, then after 3–4 days
Send Claude a screenshot of results **by ad set** (Karnataka vs USA): clicks, cost per click, landing page views.
Move money to the ad set with the cheaper landing-page views and more downloads.
